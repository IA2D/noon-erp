# NOON ERP — Finance & Accounting

تطبيق مكتبي عربي لإدارة المحاسبة والعمليات المالية، مبني باستخدام Electron وReact وTypeScript،
ويستخدم SQLite محلياً مع إسقاطات علائقية للحسابات والقيود والسندات والبيانات الرئيسية.

## الإصدار الحالي

- **الإصدار:** `1.0.0`
- **النظام:** Windows x64
- **الواجهة:** عربية RTL مع الوضعين الفاتح والداكن
- **قاعدة البيانات:** SQLite (`FULLERP.sqlite`)
- **مكان البيانات المتوافق:** `%APPDATA%\FULLERP`
- **الحزم الجاهزة:** Installer وPortable وwin-unpacked في صفحة GitHub Releases

## أهم الوظائف

- دليل حسابات شجري وحسابات تشغيلية ومساعدة.
- أرصدة افتتاحية قابلة للحفظ كمسودة والترحيل المتوازن.
- قيود يومية وسندات صرف وقبض مع تحقق مركزي قبل الترحيل.
- ترحيل فردي ويومي وضوابط إقفال مؤقت ومراجع ونهائي للشهر والسنة.
- حركة الصندوق والبنك/الصراف وكشوف العملاء والموردين والموظفين والعهد.
- قوائم مالية، ميزان مراجعة، تدفقات نقدية وتغيرات حقوق الملكية.
- عقود والتزامات واستحقاقات وتسويات مرتبطة بالمستندات المحاسبية.
- عملات متعددة وفروق عملة محققة وغير محققة وإعادة تقييم.
- سجل تدقيق غير قابل للتعديل وصلاحيات أدوار وجلسات مستخدمين.
- نسخ احتياطية محققة، استعادة تلقائية وفحص سلامة SQLite.
- معاينة طباعة Windows موحدة وتقارير A4 عمودية قابلة للطباعة حتى بدون حركات.

## التشغيل للتطوير

المتطلبات:

- Node.js 24 أو إصدار متوافق
- npm
- Windows لبناء حزم Electron النهائية

```powershell
npm install
npm run desktop:dev
```

## التحقق والبناء

تشغيل بوابة التحقق المحاسبية والتقنية:

```powershell
npm run p1:verify
```

بناء التطبيق غير المضغوط:

```powershell
npm run desktop:build
```

بناء Installer وPortable:

```powershell
npm run desktop:package
```

## بيانات الدخول الأولية للاختبار

| المستخدم | كلمة المرور | الدور |
|---|---|---|
| `admin` | `admin123` | المدير المالي التنفيذي (CFO) |
| `manager` | `manager123` | المحاسب المالي |
| `accountant` | `accountant123` | المدقق المالي |

يختار المستخدم العام الافتراضي للتقارير من شاشة الدخول، ويمكن تغيير كلمة المرور من
**الإعدادات ← الأمان وتدقيق العمليات**.

## حالات سير العمل

- حالة `مسودة` مخصصة حصرياً للأرصدة الافتتاحية.
- القيود وسندات الصرف والقبض تستخدم `بانتظار الترحيل` قبل الترحيل.
- العقود والعهد تبدأ بحالة `جديد`.

## الاختبارات الرئيسية

تغطي الاختبارات الآلية:

- توازن القيود والتحقق من الحسابات المساعدة والعملات.
- منع الترحيل المكرر وتعديل المستندات المرحلة.
- الترحيل اليومي وإقفالات الشهر والسنة.
- التقارير والقوائم والتسويات وكشوف الحساب.
- الطباعة والمعاينة والاتجاه والتقارير الفارغة.
- SQLite والعلاقات والمفاتيح الخارجية والترحيلات والنسخ الاحتياطي.
- تسجيل الدخول وتغيير كلمة المرور والصلاحيات وسجل التدقيق.
- تشغيل حقيقي للحزم المثبتة والمحمولة وغير المضغوطة.
